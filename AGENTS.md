# Project instructions

## Agent skills

### Issue tracker

Track specs and tickets as local Markdown under `.scratch/<feature>/`. Before publishing, reading, or updating tracker items, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five triage roles. Before triaging or assigning a triage status, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring a domain or proposing a design, read `docs/agents/domain.md`.
